# Notebooks Directory

This folder is reserved for Jupyter Notebooks used during exploratory research, iterative experimentation, and model development.

## Planned Notebooks
1. `01_exploratory_data_analysis.ipynb`: Class distribution analysis, image dimension inspection, sample visualization, and intensity histogram inspection.
2. `02_data_preprocessing_and_augmentation.ipynb`: Resizing, normalization, data augmentation pipelines (rotation, zoom, horizontal flip), and class imbalance handling.
3. `03_baseline_cnn_model.ipynb`: Building, training, and evaluating a custom Convolutional Neural Network (CNN) architecture.
4. `04_transfer_learning_experiments.ipynb`: Fine-tuning pre-trained architectures (e.g., MobileNetV2, ResNet50, EfficientNet) and benchmark comparison.
5. `05_explainability_gradcam.ipynb`: Implementing Gradient-weighted Class Activation Mapping (Grad-CAM) to generate visual saliency heatmaps over chest X-rays.
