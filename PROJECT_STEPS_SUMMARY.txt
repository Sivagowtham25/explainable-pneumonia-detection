STEP 5: STAGE 2 BASELINE CNN MODELING (notebooks/02_baseline_cnn_model.ipynb)
--------------------------------------------------------------------------------
1. File created: notebooks/02_baseline_cnn_model.ipynb
2. Technical implementations & decisions:
   - Dynamic Validation Partitioning: Used tf.keras.utils.image_dataset_from_directory(validation_split=0.15)
     to carve 782 validation images (15%) from train/ on-the-fly, leaving 4,434 for training.
   - Class Imbalance Mitigation: Computed balanced class weights via sklearn compute_class_weight
     (NORMAL: ~1.93, PNEUMONIA: ~0.68) and passed to model.fit(class_weight=...).
   - Clinically Safe Augmentation: RandomFlip("horizontal"), RandomRotation(0.05), RandomZoom(0.05).
     Vertical flips strictly excluded as inverted thoracic anatomy is clinically invalid.
   - Pipeline Optimization: Caching, shuffling, and prefetching with tf.data.AUTOTUNE.
   - Baseline CNN Architecture:
     * Rescaling (1./255)
     * 4 Conv Blocks (32 -> 64 -> 128 -> 128 filters, 3x3, ReLU)
     * BatchNormalization and MaxPooling2D in each block
     * GlobalAveragePooling2D (collapses spatial dimensions without parameter explosion)
     * Named final conv layer 'conv4_features' to support future Grad-CAM heatmaps
     * Dense Head: 128 units, Dropout 0.5, Sigmoid output (Total: 258,881 parameters)
   - Callbacks: ModelCheckpoint (saving to models/baseline_cnn_best.keras), EarlyStopping, ReduceLROnPlateau.
   - Diagnostic Evaluation: Evaluates best model on official test set (624 images) with Accuracy,
     Precision, Recall (Sensitivity), ROC-AUC, Confusion Matrix, and ROC Curve.
3. Verified Execution & Official Test Results:
   - Training Convergence: 15 epochs executed, EarlyStopping triggered at Epoch 15.
     Best checkpoint restored from Epoch 10 (val_loss: 0.0961, val_auc: 0.9927, val_recall: 0.9611).
   - Saved Artifact: models/baseline_cnn_best.keras (3.19 MB, 18 layers, 258,881 params).
     Successfully loaded and verified with tf.keras.models.load_model().
   - Positive Class Convention: Index 0 = NORMAL, Index 1 = PNEUMONIA.
     Outputs sigmoid probability P(PNEUMONIA | x) >= 0.5 -> PNEUMONIA.
   - Official Test Set Performance (624 Images: 234 Normal, 390 Pneumonia):
     * Accuracy                     : 83.17% (519 / 624)
     * Precision (PNEUMONIA)        : 79.63% (383 / 481)
     * Recall/Sensitivity (PNEUMONIA): 98.21% (383 out of 390 detected; only 7 false negatives)
     * F1-Score (PNEUMONIA)         : 87.94%
     * ROC-AUC                      : 0.9252
   - Confusion Matrix Breakdown:
     * True Negatives  (TN): 136 (Correctly identified Normal)
     * False Positives (FP): 98  (Normal incorrectly classified as Pneumonia)
     * False Negatives (FN): 7   (Pneumonia incorrectly classified as Normal)
     * True Positives  (TP): 383 (Correctly identified Pneumonia)

STEP 6: STAGE 3 TRANSFER LEARNING EXPERIMENTS (notebooks/03_transfer_learning_experiments.ipynb)
--------------------------------------------------------------------------------
1. File created: notebooks/03_transfer_learning_experiments.ipynb
2. Technical implementations & decisions:
   - Target Goal: Resolve the 98 False Positives on Normal scans from Stage 2 by utilizing
     pre-trained MobileNetV2 representations to boost Specificity and Overall Accuracy.
   - Two-Phase Strategy:
     * Phase 1 (Feature Extraction): Freeze ImageNet backbone (base_model.trainable = False),
       train custom classification head with Adam(1e-3).
     * Phase 2 (Fine-Tuning): Unfreeze top convolutional layers from layer 100 onwards;
       fine-tune with micro learning rate Adam(1e-5).
   - In-Graph Preprocessing: Integrated mobilenet_v2.preprocess_input ([-1, 1] normalization).
   - Checkpoint Configuration: ModelCheckpoint saving to models/mobilenetv2_transfer_best.keras.
   - Comprehensive Comparative Evaluation: Direct benchmark comparison table evaluating
     Baseline CNN vs. MobileNetV2 across Accuracy, Precision, Recall, Specificity,
     False Positives/Negatives, and ROC-AUC on the official 624-image test set.
3. Verified Execution & Official Test Results (MobileNetV2):

STEP 7: PHASE 5 EXPLAINABLE AI PIPELINE & GRAD-CAM (notebooks/04_explainability_gradcam.ipynb)
--------------------------------------------------------------------------------
1. Files created:
   - src/explainability/gradcam.py: Reusable production engine for gradient calculation,
     pooling, ReLU filtering, and PIL-based alpha blending.
   - src/explainability/__init__.py: Package exports.
   - notebooks/04_explainability_gradcam.ipynb: Interactive interpretability research notebook.
2. Technical implementations & decisions:
   - Mathematical Grad-CAM formulation computing channel weights alpha_k via Global Average Pooling
     of gradients d(y^c)/d(A^k), followed by ReLU activation to isolate positive evidence.
   - Dual-Model Architecture Support:
     * Custom Baseline CNN: Targets conv4_features (28x28x128 feature map).
     * MobileNetV2: Targets Conv_1 (7x7x1280 feature map) within the nested functional backbone.
   - High-Resolution Colormap Overlay: Bicubic interpolation resizing with JET colormap and alpha
     blending (alpha=0.4) over grayscale radiographs, maintaining rib/clavicle anatomical visibility.
   - Four Comprehensive Case Studies:
     * True Positive: Validates focal consolidation localization in pneumonia scans.
     * True Negative: Demonstrates absence of pathological focus in healthy clear lung fields.
     * False Positive Audit: Explains why cardiac shadows and scapula edges trigger false alarms.
     * Comparative Gallery: Side-by-side visual comparison between Baseline CNN and MobileNetV2.
